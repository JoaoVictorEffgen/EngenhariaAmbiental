# 🌱 Marques Engenharia Ambiental

Consultoria e licenciamento ambiental em todo o Brasil. Soluções práticas, tecnológicas e acessíveis para empreendimentos.

## 📋 Sobre

A Marques Engenharia Ambiental oferece:
- **Licenciamento Ambiental** - Licenças prévia, de instalação e operação
- **Monitoramento de Condicionantes** - Controle de prazos e requisitos legais
- **Gestão de Documentos** - Organização completa de documentação
- **Tecnologias Ambientais** - Implementação de ferramentas digitais
- **Consultoria Estratégica** - Adequação legal e estudos de impacto
- **Treinamentos** - Capacitação em boas práticas
- **PGRS** - Gerenciamento de Resíduos Sólidos
- **CTF/APP** - Cadastro Técnico Federal

## 🚀 Como Usar

### Desenvolvimento Local

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Abrir no navegador
http://localhost:8080
```

### Estrutura de Arquivos

```
.
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos CSS
├── js/
│   └── main.js         # JavaScript funcional
├── assets/
│   └── logo.svg        # Logo do projeto
├── package.json        # Dependências do projeto
└── README.md          # Documentação
```
